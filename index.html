realm

realm は、自分宛てに届く連絡から、やることの候補を拾い出すための個人用の道具です。使う人が、自分の Mac の上で動かします。

Google のアカウントで読むもの

  • Gmail のメール (読み取りだけ)
  • Google Calendar の予定 (読み取りだけ)

メールの送信、削除、予定の作成や変更はできません。求める権限は、読み取り専用の 2 つだけです。

読んだデータの扱い

プライバシーポリシー に書いてあります。

realm is a personal tool that runs on the user's own Mac. It reads the user's own Gmail messages and Google Calendar events (read-only) to list things the user needs to act on. See the privacy policy.

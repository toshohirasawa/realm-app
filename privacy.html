realm のプライバシーポリシー

最終更新: 2026-11-23

realm は、使う人が自分の Mac の上で動かす個人用の道具です。このページは、realm が Google のアカウントから読むデータの扱いを説明します。

読むデータ

  • Gmail のメール (差出人、宛先、件名、本文、添付の名前)
  • Google Calendar の予定 (名前、日時、説明、出席者、返事の状態)

権限は読み取り専用です。メールの送信や削除、予定の作成や変更はしません。

データの行き先

  • 読んだデータは、使う人の Mac に保存されます。
  • realm の配布者には、何も送られません。配布者は、使う人のメールも予定も、認可の情報も受け取りません。
  • 使う人が自分で設定した場合に限り、データはその人自身の保存先 (自分の git の repo など) と、その人が自分の契約で使う AI アシスタントに渡ります。メールや予定からやることの候補を拾う処理に、AI アシスタントを使うためです。
  • それ以外の第三者に、データを渡したり売ったりしません。広告にも使いません。

認可の情報

Google の認可で得た token は、使う人の Mac の Keychain に保存されます。ほかの場所には送りません。

やめるとき

Google アカウントの 「アカウントにアクセスできるアプリ」 で、realm の権限をいつでも取り消せます。Mac に保存されたデータは、使う人が自分で消せます。

連絡先

質問は、GitHub の issue に書いてください。

Summary in English

realm runs on the user's own Mac and reads the user's Gmail messages and Google Calendar events with read-only access. The data is stored on the user's Mac. Nothing is sent to the distributor of realm. Only if the user sets it up, the data goes to the user's own storage (such as their own git repository) and to an AI assistant the user uses under their own account, in order to pick out things to act on. The data is not shared with or sold to any other third party, and is not used for advertising. The authorization token is kept in the macOS Keychain on the user's Mac. Access can be revoked at any time from the Google Account permissions page. Questions: open an issue on GitHub.
